# HomeWork Laba10

### Домашняя работа (Условие)

Задание 2. 
Создайте мини-проект, реализующий программу системы хронометража на спортивных соревнованиях (например, лыжные гонки или биатлон). Программа должна принимать временные метки прохождения контрольных этапов в секундах, рассчитывать чистый результат, проверять его на соответствие правилам (контроль нарушений) и красиво выводить данные на экран. Вам необходимо спроектировать архитектуру приложения, состоящую из 5 взаимосвязанных функций:

int get_duration(int start_sec, int end_sec)
Вход: время старта и финиша на этапе (в секундах). Выход: возвращает чистую длительность этапа в секундах.

int check_status(int duration_sec) Вход: чистая длительность этапа в секундах. Выход: возвращает числовой код статуса заезда: • -1 — Штраф / Дисквалификация (если этап пройден быстрее 30 секунд, что физически невозможно — спортсмен срезал трассу). • 1 — Рекорд этапа (если этап пройден быстрее 45 секунд). • 0 — Норма (во всех остальных случаях).

int get_full_minutes(int total_sec) Вход: общее количество секунд. Выход: возвращает только количество полных минут.

void print_time_mm_ss(int minutes, int seconds) Вход: минуты и секунды. Функция осуществляет красивый вывод на экран в формате ММ:СС. Числа меньше 10 должны выводиться с ведущим нулем (например, 02:05). Символ переноса строки \n функция не печатает.

void process_stage(int start_sec, int end_sec) Вход: время старта и финиша. Главная координирующая функция (void). Внутри себя она обязана вызвать get_duration, передать полученный результат в check_status и get_full_minutes, рассчитать остаток секунд с помощью % 60, вызвать print_time_mm_ss и на основе кода статуса допечатать текстовый вердикт: [Дисквалификация], [Рекорд!] или [Норма].
В функции main() необходимо последовательно вводить однобуквенный код спортсмена и время старта и финиша на каждом этапе. Ввод заканчивается кода код спортсмена равен ‘!’.

Разделите программу на несколько файлов и создайте заголовочный файл для объявлений собственных функций.

### 1. Алгоритм

1. Начать программу.
2. Подключить файл `timing.h`.
3. Объявить переменные: код спортсмена, время старта, время финиша.
4. Организовать цикл ввода данных о спортсменах.
5. Ввести код спортсмена или завершит программу знаком `!`.
6. Ввести время старта и финиша.
7. Вызвать функцию `get_duration()` для вычисления времени прохождения.
8. Вызвать функцию `check_status()` для определения статуса результата:
   `-1` — дисквалификация;
   `1` — рекорд;
   `0` — норма;
9. Вызвать функцию `get_full_minutes()` и рассчитать остаток секунд с помощью `% 60`.
10. Вызвать функцию `print_time_mm_ss()` для вывода времени в формате `ММ:СС`.
11. Вывести результат спортсмена и его статус на экран.
12. Повторять, пока пользователь не введёт знак `!`.
16. Завершить программу.

# 2. Реализация программы

Программа реализована на C и разделена в три файла: `main.c`, `timing.c` и `timing.h`.

Заголовочный файл `timing.h`.

Файл `timing.c` с функциями расчёта.

Файл `main.c` содержит главную функцию `main()`.

Для ввода данных используется функция `scanf()`.

Функция `get_duration()` вычисляет время прохождения этапа в секундах.

Функция `check_status()` определяет статус результата(`get_duration()`) спортсмена.

Функция `get_full_minutes()` считает минуты и остаток секунд.

Функция `print_time_mm_ss()` выводит время.

Функция `process_stage()` выводит спортсмена, его время и статус.

Для завершения программы используется знак `!`.
